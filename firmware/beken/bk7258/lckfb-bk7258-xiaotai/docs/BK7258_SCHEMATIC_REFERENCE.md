## 当前软件配置

| 功能 | GPIO | 固件行为 |
| --- | --- | --- |
| 摄像头供电控制 | P9 | 打开前置高，关闭或失败后置低；需实测电源极性 |
| 摄像头 PWDN | P40 | SDK 复位序列最终置低 |
| 摄像头 RESET | P41 | SDK 复位序列最终置高 |
| SCCB 时钟/数据 | P42/P43 | 模拟 I2C 总线 2，100 kHz |
| 摄像头 MCLK | P27 | 当前 GC0308 档位为 20 MHz |
| 摄像头数据与同步 | P29–P39 | PCLK、HREF、VSYNC、D0–D7 |
| 功放供电 | P8 | 板级音频活动时置高 |
| 功放播放控制 | P23 | 播放时置低，静音时置高 |

摄像头档位与构建补丁见[构建身份](../BUILD_IDENTITY.md)，测量步骤见
[摄像头检查清单](../CAMERA_HARDWARE_CHECKLIST.md)。已有探测记录为地址 `0x21`、ID `0x9b`
的 GC0308 兼容传感器；换模组后需重新探测，不能仅凭 GPIO 配置推断型号。
