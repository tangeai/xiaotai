## 历史 Release：1.0.1+build.42（2026-10-22）

本次发布面向 **M5Stack CoreS3-Lite / ILI9342E**，独立标签为
`m5stack-cores3-lite-v1.0.1`，标题为 `M5Stack CoreS3-Lite v1.0.1 · build.42`。
发布构建由 main 的 `dbc262c` 执行统一 `--release` 入口生成，保留以下 build.41
功能与修复。本版本为正式 Release。

ZIP 清单中的 `BUILD_VERIFIED_HIL_PENDING` 是打包时的验证快照，不是 GitHub
发布阶段。构建身份与实板验证范围见
[验证记录](../../../boards/m5stack/cores3-lite/VALIDATION.md)。

交付包含同版分文件 ZIP、从 `0x0` 烧录的 merged BIN 和 `SHA256SUMS`。
完整镜像覆盖 Wi-Fi、绑定等 NVS 配置；网页 Flash 参数可选 Keep，保留固件内的
DIO / 80 MHz / 16 MB。固件仅适用于本板 ILI9342E 变体，不能刷入立创 S3 或 P4。

功能列表、已修复问题和限制沿用下方开发基线；短句/吞句首暂缓，录音实验已撤回，
收音、AI 打断和 AEC/UI 实时性余量仍需持续测试，弱网与长稳等专项不视为全部通过。
最新构建身份见[验证记录](../../../boards/m5stack/cores3-lite/VALIDATION.md)。

### 本次修复

- 同组连续歌曲字幕不再继承上一已完成字幕段的情绪 Tag；显式 neutral、同段局部到
  最终字幕、独立 Tag 首段应用和轮末尾音表情仍保留。用户确认歌曲嘴部示波恢复。
- ESP 设置保存使用不可变快照和单 worker，失败可重试，重置与未结束写入隔离；
  BK 同步补保存失败反馈和旧设置格式兼容，音量端点不重复写 Flash。
- BK 表情、联系人、AI 历史页面补齐，字幕及嘴部刷新不覆盖其他页面；ESP 联系人
  先进入详情再拨号，减少误触。
- 修复字幕 UTF-8 容量边界误删完整末字符，补充协议与历史连续回放。
- 保留只读音频/表情诊断；录音导出实验已撤回，本版不提供该功能。

### 问题与限制

- **M5 收音和 AI 打断仍需持续实测。** 短句“好的”识别不稳定、可能吞句首，按用户
  要求暂缓处理；本版不宣称修复。
- **实时处理余量偏紧。** build.41 用户窗口中 AEC 平均 34.385 ms，高于 32 ms
  输入周期；累计超时 485 次、处理 1387 帧。采集窗口 wall/audio=1179/1024 ms。
  UI 在 5005 ms 内刷新 26 次，累计渲染/传输 1060 ms，最长一次 165 ms。
  这些是墙钟观测，不能换算为 CPU 占用率或断定动画是瓶颈根因。
- 该快照解码失败、I2S 失败、RX 溢出、应用丢弃和当前窗口采集溢出均为零；
  累计麦克风削顶 5356，当前窗口削顶为零。单次快照不能排除间歇故障或内存泄漏。
- P4 视频通话质量已由用户接受，暂不优化；设备凭证保护不纳入本次。
- 其他板卡最新 Tag 修复后的实屏、设置重启持久化、呼叫/房间切换和长稳尚待验证。

  已显示内存中的新值，重启后却未保留。代码审查确认，尚未通过实板故障注入复现。

2026-10-22 后续：上述设置持久化失败反馈已在共享 ESP 产品层修复，增加失败重试、

## 封版后复查修复

对 `a835521...9628960` 的第二轮审查确认一处高优先级问题：S3 编码前检查会话，
编码后却直接发送。编码期间 AI 切到 VoIP 时，旧 PCM 可能由 A-law 发送入口按新连接
和流编号提交。生产 worker 与生产 SDK 路由联合回放复现了旧 AI 包进入新 VoIP 连接。

修复是在编码后、提交前重新检查会话、mute epoch、闭麦、上行/PTT 和连接就绪；
失效帧正常归还队列槽，不误报编码失败。A-law/Opus 各七种编码期间失效注入先失败，
修复后 14 组均通过；生产 SDK 联合回放也通过。检查与 SDK 调用之间仍不是跨模块
原子事务，本回归覆盖已复现的编码期间切换，不能据此声称消除了所有并发交错。

规范审查确认 1 项上述缺陷；需求审查未新增确认其他偏差。未发现新的 PSRAM/ISR
生命周期问题，P4/BK 对照未发现新增错误；结论限于代码与主机回放。
修复仅修改 S3 上行 worker，P4/BK 源码不变，未做 AEC/增益或缓存调参。

此前 M5 build.28 / 立创 build.9 与本地封版标签继续保留作历史快照，不覆盖原文件。
当前修复产物为 M5 build.29 / 立创 build.10，尚未烧录；切换、闭麦和 PTT 仍待实板复测。
