- 去掉 AI 传输连接完成、音频预热后的 300 ms 固定等待，随后发送 `start_session`。保留音频预热、会话代际检查及服务端接受后才启用麦克风的顺序。

- 增加毫秒级诊断：`AI_TIMING` 分拆 Token、传输连接、媒体准备、启动命令及接受通知和每轮响应；`AI_AUDIO` 记录接收、软件队列、解码、准备、写入耗时；`AI_UPLINK` 记录采集、DSP、发送及门控；`AI_SIGNAL` 记录控制事件排队。音频日志采样输出，不记录 Token 或对话正文。

级别 4（该 SDK 的 INFO），不启用其高等级传输诊断。INFO 下仍保留本轮计时日志。
