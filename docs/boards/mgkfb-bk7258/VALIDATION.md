双屏眼睛和实体按键、H5 实时查看、AI 对讲及微信音频通话；不支持触摸、设备互呼和多人对讲。

- 保留 v1.0.2 已验证的首个微信联系人快捷呼叫、持续回铃、音频交接和挂断恢复。
- 新增配网启动与 HTTP 探测诊断日志，不改变 DNS、HTTP 响应内容或配网启动顺序。

- 整理烧录步骤、准确文件名、红框截图、文件用途及共用串口命令说明。
- 开发与发布共用各板原生输出目录，板级接线和功能范围保持独立。
