# 立创·实战派 ESP32-S3 v1.1.0 · build.40

适用板卡：`lckfb-esp32s3`，PCB V1.0.1，ESP32-S3-WROOM-1-N16R8。
固件内版本为 `1.1.0+build.40`。此版本新增 **AI 音频识别（含哭声分析）**。

## AI 音频识别

- 仅在设备空闲时检测声音；检测到声音后保留最多 5 秒预录，再录制 10 秒音频上传。
  AI 通话、远程查看、设备互呼和微信通话期间暂停，不与这些业务争用麦克风。
- 设备端每次上传后至少冷却 1 分钟；识别类型、是否开启及月额度由服务端控制。
  额度耗尽或服务端不可用时停止上报。
- 首页顶部识别框图标可暂停或恢复本机识别。状态文字显示录制进度、上传、等待分析
  和冷却倒计时；静态提示显示 5 秒后隐藏。分析文字横向滚动两次后消失，语音结果
  通过扬声器播放。
- 与服务端识别配置、任务查询和语音下载接口对接，并处理额度耗尽、请求结果不确定
  与设备解绑等响应。

原有 H5 实时查看和对讲、AI 语音对话、设备呼叫、微信语音通话及房间功能仍在本板固件中。

## 构建和验证

`bash tools/check.sh` 通过，包含 488 项 Python 回归、既有主机 ASan/UBSan 检查
和 5 块板卡清单校验。ESP-IDF 5.5.5 原生发布构建通过。

用户确认此前版本的 AI 音频识别功能已在实板验证。`build.40` 是本次版本号和
设备能力上报版本更新后生成的新镜像，尚未有这份精确镜像的实板验证记录。
按仓库发布规则，验证包暂标记 `BUILD_VERIFIED_HIL_PENDING`，完成 `build.40`
的实板复核后再公开发布。

## 下载和升级

完整镜像 `lckfb-esp32s3-1.1.0+build.40-merged.bin` 从 `0x0` 烧录，
会覆盖 NVS 中的 Wi-Fi、绑定等配置；保留配置升级使用验证 ZIP 内的分文件清单。
下载后核对同一发布中的 `SHA256SUMS`。操作见[本板烧录指南](README.md#烧录)。
