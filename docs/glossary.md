# 常用术语

文档会在术语第一次出现时直接解释。这里集中列出常见词，便于快速查询。

| 术语 | 含义 |
| --- | --- |
| AEC | 声学回声消除，用于减少扬声器声音再次被麦克风采集的问题 |
| AI | 人工智能；本文主要指设备上的语音对话功能 |
| API | 应用程序编程接口，规定软件之间如何请求和返回数据 |
| 板卡 ID | 开发板在本仓库中的唯一名称，用于选择编译目标、生成固件包和核对烧录型号 |
| BSP | 板级支持包，包含特定开发板的基础驱动和配置 |
| DMA | 直接存储器访问，让外设不经处理器逐字节搬运数据 |
| ESP-IDF | 乐鑫物联网开发框架，用于构建 ESP32 系列固件 |
| Flash | 闪存，断电后仍能保存固件和数据 |
| GPIO | 通用输入输出引脚，用于连接按键、电源控制和其他外设 |
| H5 | 网页端；本项目中指浏览器里的设备查看和对讲页面 |
| HIL | 硬件在环测试，把真实开发板接入自动或人工测试流程 |
| H.264 | 视频压缩格式，通过关键帧和参考帧减少视频数据量 |
| HTTP | 超文本传输协议，常用于设备和服务器之间的请求 |
| I²C | 芯片间串行总线，常用于连接触摸、音频和传感器器件 |
| I²S | 数字音频总线，用于传输麦克风和扬声器数据 |
| MQTT | 轻量消息传输协议，用于设备命令、通知和状态上报 |
| MJPEG | 逐帧 JPEG 视频，每一帧都可以单独解码 |
| manifest | 清单文件；记录板卡、依赖或发布包中的结构化元数据 |
| OTA | 在线升级，设备通过网络更新固件 |
| PCB | 印刷电路板；版本不同可能导致引脚或器件变化 |
| PSRAM | 伪静态随机存取存储器，常用于音视频缓冲和大块运行内存 |
| PCM | 脉冲编码调制，本项目中通常指尚未压缩的数字音频 |
| Opus | 适合实时语音的可变长度音频编码格式 |
| SDK | 软件开发工具包，包含库、头文件、工具和示例 |
| TiRTC | 小钛项目使用的实时音视频软件开发工具包 |
| VoIP | 网络语音通话；本项目中主要指微信通话接入 |
| WHIP | 基于 HTTP 建立实时媒体连接的协议，本项目用它创建 TiRTC 会话 |
| WSL2 | 适用于 Linux 的 Windows 子系统，可在 Windows 上提供 Linux 构建环境 |

编解码器名称、器件型号和协议字段通常没有合适的中文译名。相关页面会说明它们
在当前功能中的用途，不要求使用者仅凭缩写猜测含义。
