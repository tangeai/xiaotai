# 官网开发板目录交付说明

本目录用于产品评审和后续开发交接，不包含线上业务代码。

## 交付物

- `PRODUCT_REQUIREMENTS.md`：前台目录、开发板详情、后台配置、发布规则与验收标准。
- `prototype.html`：官网开发板目录原型。点击前两款真实示例的“详情”可查看资源、购买声明和效果视频入口。
- `admin-prototype.html`：后台资料管理原型。可体验新增、编辑、图片选择预览和发布选项。
- `prototype*.css`、`admin-prototype.css`：上述原型的样式文件。

## 评审方式

直接用浏览器打开 `prototype.html` 和 `admin-prototype.html`。两个页面均为静态交互原型，保存、上架、下架和上传操作不会写入服务器。

## 开发边界

- 官网顶部导航复用现有首页组件与样式，不单独维护。
- 官网只消费后台已上架数据；开发板数据不得写死在正式页面。
- 图片应上传到对象存储，后台保存资源 URL；外部链接为空时，前台隐藏对应入口。
- 本交付不修改 `tirtc-server-example`，也不包含后台接口、数据库迁移或线上发布。

## 建议开发顺序

1. 建立开发板数据表、状态枚举及管理权限。
2. 实现图片上传、CRUD、排序和上下架接口。
3. 实现后台列表和编辑表单。
4. 接入官网目录与详情页面，并复用官网导航。
5. 按 PRD 验收前 20 款图片区、第 21–100 款文字目录、可选视频与外链隐藏逻辑。
