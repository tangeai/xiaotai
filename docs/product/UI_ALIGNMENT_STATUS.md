## AI 情绪 Tag 与嘴部动效

明确的服务器情绪 Tag 控制完整表情并关闭示波。没有有效 Tag、使用本地默认表情时，
播放驱动嘴巴，眼睛保持眯眼；S3/BK 使用七列点阵，P4 使用波形。默认 `happy` 与
服务器明确返回的 `happy` 通过 `emotion_tag_present` 区分，不能混为一谈。

M5 日志 `ai=1 phase=3 tag=1 emotion=happy pcm=1 columns=6566566` 表示有效
情绪 Tag 与播放并存；此时关闭示波符合用户确认的规则，不能将它判定为缺陷。
此前 build.35 允许 Tag 与示波共存，违反该规则，已撤回这项源码改动；不再推荐该
固件。只读诊断继续保留，不改变媒体采样、增益或 AEC。

P4、立创 S3、M5 的组件 CMake 均编译同一份 ESP 界面源码，当前已恢复原 Tag 优先
逻辑；BK 独立实现本来就使用该优先级，无需同步 build.35 的改动。
历史提交 `96a6dd3`（2026-10-10，ESP）、`d1dfb73`（2026-10-14，BK）确实加入
Tag 优先；`70d48a4` 的 S3 点阵及 `9c54b57` 的 M5 适配继承它。这是预期策略的历史，
不是已确认的缺陷引入点。原测试的 `full TAG face wins` 也符合要求。

回归 `test_playback_waveform.py` 先复现错误共存行为，再验证 Tag 完整表情、PCM
变化不覆盖 Tag、切回无 Tag 后眯眼与示波恢复、停止播放及预览隔离。
`test_ai_view.c` 验证默认 happy、显式开心 Tag 和下一条无 Tag 回复的真实协议转换。
既有 BK 动效测试保护原优先级。主机检查不替代同一固件的有/无 Tag 播放实屏验收。

M5 `1.0.1+build.36` 原生构建及 BIN/ELF 身份核对通过；`bash tools/check.sh` 通过
431 项工具测试、产品核心 ASan/UBSan 与五板清单，未烧录。精确身份见
[VALIDATION.md](../../boards/m5stack/cores3-lite/VALIDATION.md)。

后续 build.36 用户采样为 `tag=1 emotion=happy pcm=1`，七列数据持续变化，
确认关闭示波的直接条件仍是有效 Tag。设备新诊断 `AI face trace` 记录本条消息情绪、
字幕分组、Tag 前后状态与快照同步结果，用于区分当前歌曲 Tag 与介绍语 Tag 保留。
不改变表情优先级；后续歌曲消息证据及修复如下。

M5 诊断版 `1.0.1+build.38` 已原生编译并核对 BIN/ELF，433 项工具测试、产品核心
ASan/UBSan 与五板清单通过，尚未烧录。用户观察对应的 build.36 已保留精确产物；
新诊断不能代替歌曲开始阶段的实板消息证据。

最新歌曲日志确认：前段 `happy final=1` 后，多条无 Tag 的同组最终字幕仍为
`tag=1->1`。共享解析器现按完成字幕段清除旧 Tag，保留同段 partial→final、
独立 Tag 首段应用、显式 neutral 及 round_end 尾部语义。S3/P4/BK7258
同用该解析器，满足相同序列时均受影响；本轮只生成 M5 `1.0.1+build.41`。
公开解析接口回归先失败后通过，全量 433 项工具测试及产品 ASan/UBSan 通过。
原生构建通过，尚需烧录后验证歌曲嘴部动效；其他板旧固件需重新编译。
最新日志未附固件身份，不将其记作某构建的实板 PASS。

用户随后确认歌曲嘴部恢复。进一步复查补充 504 组共享解析器组合，覆盖全部情绪、
三种 Tag 来源、追加/替换字幕、缺省 ID 和时钟回绕；当前实现通过，恢复旧继承条件的
临时源码副本失败。该轮没有新增生产代码修改，其他板卡的实屏与长稳验证仍待完成。

## 2026-10-22 已知缺口修复

本轮沿用现有交互与媒体范围，M5 收音/AI 打断继续实测，P4 视频质量已由用户接受，
正点 S3 暂不跟进，设备凭证保护不纳入当前工作。

- ESP 设置保存改为单个内部栈 worker，使用不可变快照；连续修改合并为下一次保存。
  NVS 打开、逐项写入、提交及建任务失败均保留失败状态，设置页显示“保存失败，重试”。
  当前参数仍在内存生效，失败不表示已持久化；点击重试保存当前值。重置在旧写入尚未
  退出时失败供重试，避免清除后旧任务写回；取消重置后仍可保存待处理修改。
- BK 设置保存错误同样可见且可重试；音量端点不再重复写 Flash。回应声男/女选择、
  单次试听及持久化已接入，试听不能抢占实时音频或绑定播报；建任务、分配、驱动播放
  失败有返回路径。保留验证码三次播报及取消语义。本项没有新增 BK 本地唤醒功能。
- BK 表情改为 21 项分页目录、独立预览、明确应用到主页；浏览/返回不改变选择，
  应用后持久化。兼容旧的五字节、六字节设置记录，新增字段使用默认值。
- BK 通讯录使用三项一页及有界上一页/下一页，列表缩短时收敛页码，保留平台联系人
  顺序及来源、设备在线状态；详情返回原列表。ESP 列表移除直接拨号按钮，统一先进入
  详情，减少误拨；平台首联系人和首页微信快捷入口策略不变。
- BK 功能菜单的 AI 聊天进入独立历史页，保存最近 12 条有界记录于 PSRAM；同条字幕
  更新覆盖局部结果，区分说话方、轮次与会话。历史页可前后查看，返回结束 AI 后回菜单；
  AI 字幕和点阵刷新不覆盖用户已进入的设置/历史页面。首页仍使用原有表情与播放动效。
- 复查确认 ESP 运行状态页已具备音频收发/丢弃、预录音和事件诊断，旧记录中的“待补齐”
  已过时；这不代表 BK 提供相同的底层计数，也不新增周期任务扫描。

## 实板复核清单

- 三板分别拍摄设置、房间入口、密码输入、单页/多页成员、退出确认；中文字、数字和英文
  使用对应字号，无缺字回退、换行孤立标点、遮挡或按钮误触。
- 设置减/加到端点后不循环，重启保留；驱动拒绝时不误保存；只调整目标设置。
- 设置中网络信息返回设置页；菜单运行状态的资源/音频/事件能切换、刷新与返回。
- 重置取消不清数据；确认后只清三类用户数据，失败提示重试，重复点击不重复执行；
  成功重启进入配网并可重新绑定。此项会清除实板用户数据，须在指定测试设备上单独验收。
- 12 人列表逐页检查，第一页/末页边界正确；发言和增减更新不跳页；显示人数小于在线总数
  时没有虚构成员或虚假页数。
- 连续按住 PTT 时成员状态更新不打断，松开或真实触控故障释放上行；翻页不触发发言。
- 退出确认间隔不响应；取消继续收听；确认释放媒体并回首页；返回仅结束本地媒体并保留分配。
- AI 多轮与尾音、一对一通话和房间切换仍正常，无 IPC 心跳断言、任务数持续增加或资源泄漏。

绑定页秒数倒计时：BK/S3/P4 使用同一产品文案与临时凭证到期时间，验证码下方
显示“有效期剩余 N 秒”；到期刷新，页面重建不重置。主机测试覆盖期限、到期、
无效凭证、正常/语音失败布局；三板倒计时及自动刷新实屏验收待完成。
